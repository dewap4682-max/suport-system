## 2. Langkah setelah upload (wajib, ±10 menit)

### a. Daftarkan ke Google Search Console
1. Buka **https://search.google.com/search-console** → **Add property** → **URL prefix**
2. Isi: `https://dewap4682-max.github.io/suport-system/`
3. Verifikasi dengan salah satu cara:
   - **HTML tag** → salin `<meta name="google-site-verification" content="...">` → kirim ke saya, saya pasang di `<head>`
   - atau **HTML file** → unduh file verifikasi → taruh di folder repo (saya bantu tempatkan)
4. Setelah terverifikasi → menu **Sitemaps** → isi `sitemap.xml` → **Submit**

### b. Minta pengindeksan
- Search Console → **URL Inspection** → tempel URL situs → **Request Indexing**
- Ulangi untuk `https://dewap4682-max.github.io/suport-system/#paket`, `#aplikasi`, `#galeri`, `#area`

### c. Bing / DuckDuckGo (opsional)
- **https://www.bing.com/webmasters** → Add site → impor langsung dari Search Console

## 4. Yang perlu Anda tahu (jujur)

- **Google butuh waktu.** Pengindeksan awal biasanya 3–14 hari; peringkat untuk kata kunci kompetitif
  (“jasa pembuatan website solo”) bisa 1–3 bulan dan sangat dipengaruhi backlink + Google Business Profile.
- **Domain GitHub Pages** (`github.io`) kurang kuat untuk SEO lokal dibanding domain sendiri
  (`suportsystem.id`). Bila nanti memakai domain sendiri, semua URL di `<head>` + sitemap + robots harus
  diganti — beri tahu saya, saya sediakan versi siap ganti.
- `meta keywords` sudah dipasang, tetapi Google **tidak** memakainya sebagai faktor peringkat
  (Bing masih membaca sedikit). Nilai sebenarnya ada pada judul, deskripsi, isi halaman, dan structured data.
- Structured data belum menjamin *rich result* FAQ — Google membatasi tampilan FAQ untuk situs
  pemerintah/kesehatan sejak 2023, tetapi datanya tetap membantu pemahaman mesin.

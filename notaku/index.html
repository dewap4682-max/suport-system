Cara Pasang

Android / Tablet (Chrome)Buka edisi pilihan Anda di Chrome → menu titik tiga di kanan atas → Tambahkan ke layar utama / Install app.
iPhone / iPad (Safari)Buka edisi pilihan Anda di Safari → tombol Bagikan → Tambahkan ke Layar Utama.
Windows (Edge / Chrome)Buka edisi pilihan Anda → ikon Install di address bar → Install.
Mac (Chrome / Safari)Chrome: ikon Install di address bar. Safari (Sonoma+): File → Add to Dock.

Di Android (Chrome): ketuk tombol Pasang aplikasi di atas, atau menu ⋮ → Instal aplikasi. Di iPhone: buka dengan Safari → tombol Bagikan → Tambahkan ke Layar Utama. Setiap edisi dipasang terpisah, jadi bisa punya beberapa ikon sekaligus.
